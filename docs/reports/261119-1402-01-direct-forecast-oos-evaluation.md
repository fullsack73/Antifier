# 직접 예측 완료 기간 오차 평가

- 기존 직접 Transformer의 조기 종료용 검증 오차와 별도로, 각 과거 시점의
  학습 창만 사용한 예측을 완료된 미래 수익률과 비교하는 진단 CLI를 추가했다.
- 날짜별 예측과 완료일, 기간 로그수익률, 오차, 내부 검증 RMSE 및 실패 사유를
  저장한다. 평가 시점은 horizon 간격으로 두며 미완료 예측은 점수화하지 않는다.
- CSV 가격과 입력 hash를 기록한다. 빈 예측은 실패로 집계하며 자료가 부족하면
  지표는 null이다. historical diagnostic이므로 자동 승격 근거가 아니다.
- 서비스 예측 및 optimizer의 uncertainty 계산은 변경하지 않았다. 실측 오차를
  서비스에 적용하려면 별도의 충분한 표본과 보정 검증이 필요하다.
- 기존 forecast-failure의 미실행 통제는 재실행하거나 완료 처리하지 않았다.
