# 22종목 공동 모델의 종목 간 attention 효과 비교

- 사용자 요청으로 기존 11개 섹터 22종목을 대상으로 시간 attention만 있는
  공동 모델과 시간 요약 뒤 종목 간 attention 한 층을 추가한 모델을 비교한다.
  MASTER 전체 재현이 아니며 단일종목 서비스 모델과도 구조가 다르다.
- 두 모델은 입력·정규화·purge·학습률 0.001·폭 32·2 heads·batch 날짜 8개·
  5 epoch 고정을 공유한다. Seed 42/43/44, 같은 8개 평가일에 각각 실행하며
  한 seed에서는 실행 순서를 뒤집는다. 504개 가격으로 학습하고 다음 63일을 평가한다.
- 총 48회 공동 모델 학습, seed별 176건의 같은 미래 outcome을 평가한다.
  528행은 독립된 528개 미래 관측이 아니다. 날짜 bootstrap은 8개 시장 시점의
  설명용 구간이다. 0 수익률 기준과 전체·seed별·섹터별 성과를 함께 기록한다.
- 신규 지표·짝지은 실행·checkpoint 재사용 검사 2개와 데이터 미래 유입/
  종목 관계 전달 검사 2개 통과. 0 기준을 추가한 뒤 지표/실행 검사 2개도 통과.
  전체 테스트와 서비스 모델 변경은 수행하지 않았다.
- 출력: `logs/stock-attention22-20261124-HH7LWA/`.
  입력과 설정은 실행 전에 고정하며 완료 전 성능 개선을 주장하지 않는다.
  이미 소비된 과거 자료의 진단으로 독립 승격 근거가 아니다.

## 완료 결과

- 종료 코드 0. 공동 모델 학습 48회, 176개 공통 stock-date를 3개 seed로
  반복한 528행 모두 완료됐다.
- 시간 attention만 사용한 모델/종목 관계 추가 모델의 RMSE는
  0.132893/0.132279, MAE는 0.105213/0.104649로 점 예측 오차가 소폭 감소했다.
  그러나 평균 rank IC는 0.11638/0.08420, 상하위 로그수익률 spread는
  0.030964/0.022536으로 종목 선택 지표는 낮아졌다.
- 종목 관계 모델의 날짜별 MSE 개선은 seed 평균 기준 3/8개 시점이었다.
  paired MSE 차이의 날짜 bootstrap 설명용 95% 구간은
  [-0.00088200, 0.00050385]로 0을 포함한다.
- 종목 관계 모델은 seed 42에서 평균 rank IC -0.04964, spread -0.01416으로
  음수였고, seed 44에서는 시간 모델보다 개선됐다. 일반적 알파 개선을 확인하지 못했다.
- 모델당 5 epoch 학습 중앙값은 시간 모델 6.277초, 종목 관계 추가 모델
  6.983초였다. 총 fit 시간은 각각 167.22초, 181.08초다.
- 서비스 모델을 변경하지 않았다. 결과는 출력 폴더의 `analysis.json`에 기록했다.
