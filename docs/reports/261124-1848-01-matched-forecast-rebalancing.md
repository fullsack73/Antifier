# 예측 기간과 리밸런싱 간격을 맞춘 Transformer MPT 비교

- 사용자 요청: 21일 예측은 21일마다, 42일 예측은 42일마다 재계산하는 경우를 비교한다.
  후보를 21/21, 42/42, 63/63, 126/126거래일로 사전 고정한다.
- 기존 11개 섹터 22종목, 최초 체결 2023-12-28~2025-12-31, 공통 503개 일수익률,
  rolling 학습 504개 가격, 60일 입력, 위치 인코딩/시간 attention/시간 요약 이후
  종목 attention, 0.5 표준화 MSE + 0.5 (1-횡단면 Pearson), seed 42/43/44,
  5 epoch, 학습률 0.001, batch 날짜 8개를 공유한다. Target/purge/연율 변환은
  각 실제 예측 기간에 맞추고 train-only scaler를 쓴다. 다른 조건은 고정한다.
- 무위험 연 3%, 비용 10 bps, 종목당 최대 20%, 2% band, 회당 총 회전율 35%
  상한이다. 초기 매수는 기존 엔진대로 상한 면제/비용 포함. 리밸런싱 횟수는
  21/42/63/126일에서 각각 24/12/8/4회다. 모든 후보의 처음과 끝은 같다.
- 직전 종가까지의 정보로 다음 거래일 종가에 체결하며 마지막 보유 기간은 h-1일이다.
  처음 매수 비용도 순 일수익률에 포함하고 복리 순자산/Sharpe 일치를 검사한다.
- 주 지표는 세 seed 로그예측 평균의 max-Sharpe MPT 순 Sharpe다. 같은 일정의
  Ledoit-Wolf GMV를 대조군으로 두고 개별 seed 결과/GMV 대체 횟수도 기록한다.
- 이전 분기 고정 재계산 연구의 source/data/package/config와 개별 checkpoint SHA를
  검증해 같은 h/origin/seed의 예측만 복사 재사용한다. 새로운 시점은 추가 학습한다.
  예상 전체 144 fit 중 재사용 72개/신규 72개이며 prepare-only로 실행 전에 확정한다.
  기존 결과 파일은 덮어쓰지 않는다. 63/63은 같은 과거 결과를 정확히 재생해야 한다.
- 같은 예측 기간의 기존 63일 재계산 성과와 paired 비교하고, 새 후보 대 63/63 및
  새 후보 대 같은 일정 GMV도 63일 블록/2000회 bootstrap 설명용 구간을 계산한다.
- 주기가 짧으면 회당 회전율 상한 35%를 더 자주 사용할 수 있으므로 연간 매매
  예산까지 동일한 실험은 아니다. 실제 회전율/비용을 함께 기록한다. 새 예측 시점도
  늘어나므로 단순히 기존 8개 예측의 보유 기간만 바꾼 결과가 아니다.
- 이미 사용한 과거 가격/고정 생존 종목군의 진단이며 독립 holdout 최적값으로
  주장하지 않는다. 서비스 기본 기간과 리밸런싱을 자동 변경하지 않는다.
- 관련 캘린더/동일 기간/실제 거래 엔진/비용/RF/단위/집계 검사 6개만 실행한다.
