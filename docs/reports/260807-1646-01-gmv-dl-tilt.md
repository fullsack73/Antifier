# 작업 기록 - GMV 기반 고정 DL Alpha Tilt 진단

- 에이전트: Codex
- 작업 유형: 포트폴리오 연구 진단

## 요약

- plain Ledoit-Wolf GMV를 기준으로 pooled Patch Transformer + frozen Kronos의 횡단면 rank가 작은 방향성만 주는 포트폴리오를 실험했습니다.
- gamma는 validation 결과를 보며 선택하지 않고 요청 시점에 `0.025`로 한 번 고정했습니다.
- 거래비용과 실행 제약을 반영한 결합 945일에서 수익률과 Sharpe는 소폭 높아졌지만 변동성도 증가했고 paired 95% gate를 통과하지 못했습니다.
- 결과는 `diagnostic_only`, `promotion_safe=false`이며 production Ledoit-Wolf GMV는 변경하지 않았습니다.

## 사양

- 포트폴리오: `w=project_capped_simplex(w_GMV+gamma*alpha_tilt)`
- alpha tilt: 횡단면 score rank 중심화, L1 norm 2
- gamma: `0.025`
- 실행: 거래비용 10 bps, rebalance band 2%, turnover cap 35%, 자산별 cap 20%
- 비교: 동일 가격·리밸런싱·실행 엔진의 plain GMV
- 추론 입력: pooled Patch Transformer + frozen Kronos의 저장된 OOS score
