# 백테스트 설정 화면 간소화

- 기존 React/CSS와 녹색 테마, 큰 제목을 유지한다.
- 반복 소개를 제거하고 CSV 형식 안내를 한 줄로 줄인다. 실험/데이터 제한 설명은
  설정 하단의 접힌 실행 조건으로 이동한다.
- CSV/평가 기간을 데스크톱에서 병렬 배치하고 모바일에서는 세로 배치한다.
- 학습 일정은 기본 노출, 거래 설정은 값과 검증을 보존한 접기 UI로 제공한다.
  잘못된 필드가 있으면 설정을 열어 수정할 수 있다.
- 전략 선택과 실행 영역을 분리하고 빈 중복종목 안내는 제거한다.
- API, 모델, 거래 조건 기본값과 저장/재개 흐름은 바꾸지 않는다.

검증: lint, Vitest, production build. 브라우저 390/848/1440px에서 넘침 없음,
거래 설정 값 유지와 한국어 표시 확인. 기존 build의 큰 bundle 경고는 유지된다.
