# 완료 예측 오차 기반 ARIMA·Transformer 혼합

- 현재 평가일 이전의 서로 겹치지 않는 3개 예측 구간에서 각 모델을 실제로
  다시 학습하고, 평가일 전에 완료된 로그수익률 오차로 혼합 비중을 계산한다.
- ARIMA의 역오차 비중을 50:50 방향으로 절반 수축해 25~75%에 제한한다.
  3개 구간 중 하나라도 구성요소를 얻지 못하면 50:50을 사용한다.
  구성요소 하나만 성공한 경우 기존 단독 예측 fallback을 유지한다.
- 이전 모델 예측과 혼합하지 않도록 모델/forecast-rank 캐시 버전을 변경했다.
  기간 로그수익률과 연율 로그수익률은 기존 계약을 유지한다.
- 세 차례 추가 재학습으로 ARIMA + Transformer의 계산량이 커진다. 진단의
  `completed_weight_periods`와 `arima_weight`로 적용 여부를 확인한다.
- `tools/compare_adaptive_hybrid.py`는 같은 종목·날짜의 공통 완료 표본에서
  ARIMA, Transformer, 50:50, 적응 혼합의 RMSE/MAE 및 rank IC를 비교한다.
  소비된 과거 자료를 활용한 결과는 독립 승격 근거가 아니다.
- 기존 원인 진단의 미실행 7개 통제를 재실행하지 않았다. 전체 테스트는 사용자
  요청에 따라 실행하지 않았으며 변경 관련 집중 테스트만 수행했다.

## 2026-11-20 섹터 확대 결과의 혼합 실패 진단

재학습 없이 `logs/adaptive-sectors-20261119-B7hUe4/results/rows.jsonl`의
22종목×8개 시점 176건을 재계산했다. 상세 수치는 같은 폴더 상위의
`mixture_diagnosis.json`에 저장했다.

- 두 모델 오차의 상관은 0.94135, 같은 부호로 틀린 경우는 165/176건이다.
  ARIMA의 MSE는 0.021243, Transformer는 0.018812로 ARIMA가 더 컸고
  오차 상쇄가 이를 충분히 보완하지 못했다. 동일가중 MSE의 분산/교차오차
  항등식과 실제 출력의 가중합을 1e-12 허용 오차로 검산했다.
- 적응 혼합이 동일가중보다 절대 오차가 작았던 경우는 80/176건이다.
  평균 ARIMA 비중은 50.386%였다. 동일가중 대비 MSE 증가 0.00012930은
  변경 방향 항 0.00011740과 변경량 제곱 항 0.00001190으로 정확히 분해된다.
  이는 저장된 표본의 산술적 설명이며 시장 국면 변화의 인과 증명이 아니다.
- 현재 비중 공식은 구성요소별 MSE만 사용하고 교차오차를 반영하지 않는다.
  전체 결과를 사후에 사용해 고정 비중을 계산하면 교차오차 무시 시 ARIMA
  46.97%, 포함 시 4.65%다. 미래 정보를 사용한 설명용 수치이며 사용할 수
  있는 가중치나 개선된 OOS 결과가 아니다. 25~75% 제한도 약한 모델을
  배제할 수 없게 한다.
- 구현상 현재 모델은 가격 504개를 사용하지만, 가중치용 과거 모델은 현재
  창을 잘라 315/378/441개를 사용한다. 직접 Transformer의 purge 후 학습
  행은 각각 110/167/224개로 현재 모델의 280개와 다르다. 따라서 같은 학습
  창을 유지한 실제 과거 예측 기록과 다르며 가중치 판단을 왜곡할 가능성이 있다.
  영향 크기는 같은 504개 과거 창을 사용한 별도 비교 없이 확정하지 않는다.
- ARIMA 출력이 사실상 0인 건은 114/176건이다. 단순 0 수익률 기준 RMSE는
  0.13682로 Transformer 0.13716보다도 조금 작다. 낮은 전체 수익률 오차가
  곧 알파를 뜻하지 않으며 손실 기준과 종목 순위 기준을 구분해야 한다.
- 과거 구성요소 오차 자체와 ARIMA fallback/수렴 상태는 원시 행에 없으므로
  짧은 표본, 수렴 실패, 시장 국면 변화 각각의 인과 기여도는 확정하지 않았다.
  코드 변경, 재학습 및 전체 테스트는 실행하지 않았다.
