# 직접 Transformer 시간 순서 입력

- 서비스 직접 Transformer의 기존 위치 인코딩을 켜 입력 수익률의 시간 순서를
  표현한다. ARIMA + Transformer의 직접 Transformer 구성요소에도 적용된다.
- 모델 버전과 forecast-rank 캐시 schema를 변경해 기존 위치 정보 없는 예측을
  새 모델 결과로 재사용하지 않는다. 후보 검색의 예측 캐시와 일반 예측/pipeline
  캐시는 기존 모델 버전 키를 통해 함께 분리된다.
- 학습 목표, horizon, 불확실성 계약, 실패 시 no-view 및 GMV 기본값은 유지한다.
- TensorFlow 실제 모델에서 순서를 뒤집은 입력의 출력이 달라지는지와 cache key
  분리, 기존 예측 및 후보 검색 계약을 회귀 검사한다.
- 이전에 사용한 세 종목 과거 자료의 동일 예측일 비교는 `logs/direct-position-20261119-hvbLVa/`에
  별도 진단으로 기록한다. 이 자료는 독립 승격 근거가 아니며 위치 인코딩이
  정확도를 높인다고 가정하지 않는다. 기존 미실행 진단 통제는 재실행하지 않았다.
