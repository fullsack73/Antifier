# 혼합 가중치의 완료 이력 3회·12회 비교

- 사용자 요청에 따라 완료된 예측 이력을 3회에서 12회로 늘려 비교한다.
  결과를 본 뒤 이력 길이를 다시 고르지 않으며, 기존 11개 섹터·22종목의
  같은 8개 평가 시점과 63일 horizon, 504개 가격 학습을 유지한다.
- 과거 12회는 약 3년이다. 교차오차 반영/무시 각각 3회·12회를 비교하며
  50% 동일가중 수축과 25~75% 비중 제한은 동일하다. 서비스 설정은 바꾸지 않는다.
- 각 종목의 과거 20개 시점에 대한 구성요소 예측을 한 번씩 계산한다.
  총 440건의 구성요소 학습 결과로 176건의 공통 평가 행을 만든다.
  현재 예측 outcome은 혼합 가중치 계산에 사용하지 않는다.
- 충분한 선행 가격과 동일 평가일, 입력·source hash는
  `logs/hybrid-history-20261120-J9x7Im/experiment.json` 및 실행 manifest에 고정한다.
  결과는 같은 폴더의 `analysis.json`에 전체·섹터별 지표, 날짜별 승패,
  비중 안정성과 함께 집계한다. 완료 전에는 개선을 주장하지 않는다.
- 연구 도구의 가중치/서로 다른 표본 수/미래 outcome 제외 관련 집중 검사
  10개 통과. 전체 테스트는 실행하지 않았다. 소비된 과거 자료이며
  독립 검증이나 생산 모델 승격 근거가 아니다.

## 완료 결과

- 종료 코드 0. 구성요소 예측 440건과 공통 평가 176건 모두 완료됐다.
- 교차오차 무시의 3회/12회 RMSE는 0.139386/0.139346, MAE는
  0.111906/0.111864, 평균 rank IC는 0.06310/0.06352였다. 변화는 작고
  12회가 날짜별 MSE에서 나은 경우는 5/8개, 개별 절대 오차는 90/176건이다.
- 교차오차 반영의 3회/12회 RMSE는 0.140441/0.141143, MAE는
  0.113030/0.113216, 평균 rank IC는 0.04969/0.01087이었다. 12회가
  날짜별 MSE에서 나은 경우는 3/8개, 개별 절대 오차는 72/176건이다.
- 교차오차 반영의 비중 표준편차는 22.64%p에서 20.00%p로 줄었고,
  25%/75% 제한값에 도달한 경우는 128건에서 88건으로 감소했다.
  비중 안정화가 이번 표본의 예측 정확도 개선으로 이어지지는 않았다.
- 따라서 이전 3회 표본 부족만을 성능 부진의 유일 원인으로 해석할 수 없다.
  오래된 이력 포함의 영향과 모델 오차 구조의 각각의 인과 기여도는 미확정이다.
- 서비스 설정은 변경하지 않았다. 전체 결과는
  `logs/hybrid-history-20261120-J9x7Im/analysis.json`에 저장했다.
