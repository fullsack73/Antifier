# Transformer 예측 기간과 분기 MPT 성과 비교

- 사용자 요청: 현재 63거래일 예측보다 적절한 예측 기간을 실험해 확인한다.
- 후보는 결과 확인 전 21/42/63/126거래일(약 1/2/3/6개월)로 고정한다.
  이전 종목 간 attention + MSE/상관 결합 Transformer MPT의 다른 조건은 유지한다.
- 기존 11개 섹터 22종목, 2023-12-28~2025-12-31 실행 구간, 63거래일 재계산,
  무위험 연 3%, 비용 10 bps, 종목당 최대 20%, 2% band, 회전율 35% 상한을 공유한다.
  예측 horizon과 매매 간격을 구분하며, 기간을 짧게 했다고 매매 횟수를 늘리지 않는다.
- 시점별 504일 학습 창, 60일 입력, 위치 인코딩/시간 attention/시간 풀링 이후 종목 간
  attention, 전역 train-only scaler, 0.5 표준화 MSE + 0.5 (1-횡단면 Pearson),
  5 epoch, 학습률 0.001, batch 날짜 8개, seed 42/43/44를 공유한다.
- 각 horizon에 맞는 완료 target과 purge를 사용한다. 학습 날짜 수는 21/42/63/126일
  각각 360/320/280/161개, 검증 날짜 수는 43/41/39/32개다. 같은 504일 이력에서
  기간이 길면 완료된 학습 표본과 gradient update 횟수가 줄어드는 현실적 설정이다.
  표본 수까지 통제한 순수 target-length 인과 효과 실험은 아니다.
- 각 기간의 로그예측을 역변환하고 expm1(period_log*252/horizon)으로 MPT에 넣는다.
  연율 변환을 63일로 고정하는 단위 오류를 방지한다. 기하 수익률 proxy라는 한계는 유지한다.
- 기간마다 8개 시점/3개 seed로 24 fit, 전체 96 fit를 모두 재학습한다.
  63일 후보를 먼저 수행하며 이전 산출물의 5개 포트폴리오 Sharpe와 차이 1e-5 이하를
  확인한 뒤 다른 후보를 진행한다. 이전 checkpoint를 source 검증 우회해 재사용하지 않는다.
  기존 helper 기본값은 63일로 유지하고 기존 result/manifest는 덮어쓰지 않는다.
- 주 지표는 사전 고정한 시드 3개 로그예측 평균 MPT의 2년 순 Sharpe다.
  같은 503개 일수익률/8회 리밸런싱에서 비교하고, 개별 seed Sharpe/GMV fallback도
  기록한다. GMV 일수익률이 모든 후보에서 같고 달력이 일치하는지 확인한다.
- 보조 예측 지표는 모든 horizon의 실제 미래가 완료된 같은 7개 origin/154개 stock-date에서
  기간 로그수익률 RMSE/MAE, 0 및 과거 504일 평균 일로그수익률*horizon 기준의 MSE skill,
  날짜별 rank IC를 기록한다. 원시 RMSE의 기간별 스케일 차이로 후보를 고르지 않는다.
  126일의 마지막 미완료 target은 예측 오차에서 제외하되 해당 예측의 포트폴리오는
  다음 분기의 완료된 실제 거래 성과로 포함한다. 126일 실제 outcome은 시점 간 중첩된다.
- 후보 대 기본 63일의 paired 일수익률 63일 블록 bootstrap 2000회는 설명용이다.
  최고 과거 Sharpe는 네 후보 중 탐색 결과이며 독립 holdout 최적값이 아니다.
  소비한 과거 자료/고정 생존 종목군/시드 동일 outcome 반복의 한계를 유지한다.
