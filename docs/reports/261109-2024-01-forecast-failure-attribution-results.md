## 3. 확인된 구현 문제와 확인되지 않은 가설

- **구현으로 확인:** 위치 정보 없는 attention+평균 풀링은 입력 순서 반전에
  사실상 불변이었다. 그러나 실제 시장에서 위치 정보 추가의 단독 기여는
  Holm 보정 후 유의하지 않았다(단순 위치 개입 p=0.12994, 주효과 p=0.08796).
- **구현으로 확인:** 단독/혼합의 clipping 계약이 달랐다. 제한을 제거하면 오히려
  오차가 커졌으므로 clipping 자체를 시장 예측 실패의 단일 원인으로 보지 않는다.
- **구현으로 확인:** ARIMA가 예측 평균 경로의 표준편차를 불확실성으로 보고하고,
  기존 Transformer는 학습 구간 RMSE를 사용한다. 이는 미래 오차 calibration
  문제이며 point forecast 부진의 직접 원인으로 입증한 것은 아니다.
- **증거 부족:** 5→50 epoch, 504→1,008일 Transformer 학습 창 증가는
  보정 후 개선이 확인되지 않았다. 단순한 학습량 부족만으로 설명할 수 없다.
- **증거 부족:** 가격 ridge에 시장 요인과 PIT 재무 정보를 추가해도
  MSE 0.0405517→0.0414844→0.0417500으로 개선되지 않았다.
  정보 부족이 제1원인이라는 사전 가설은 이번 실험에서 지지되지 않았다.
  모든 정보가 무가치하다거나 다른 표현/모델에서도 신호가 없다는 결론은 아니다.
- **미해결:** 시장 구간 의존성, 수렴 문제, target/rollout 기여 분해,
  직접 예측의 독립 데이터 일반화는 아직 확정하지 못했다.

수정 전 runner/core source를 출력 디렉터리에 보존했다. 재생한 `result.json`은
`report_source_hashes`로 분석 코드 버전을 따로 남긴다. 기존 혼합의 observed
MSE와 구성요소 재구성 MSE가 1e-12 이내로 일치함을 검산했다.

별도 TODO로 보존하며 새 예산 없이 재실행하지 않는다. 모든 결과는 consumed
public-data diagnostic이며 production 변경이나 독립 alpha 승격 근거가 아니다.
