# 10종목 공동 Transformer의 종목 간 attention 시간 측정

- 사용자 요청으로 서로 다른 분야의 10종목 MSFT/C/BMY/AMZN/KMB/HON/PPL/O/COP/GOOG를
  사용해 시간 attention만 있는 공동 모델과, 시간 요약 뒤 종목 간 attention
  한 층을 추가한 공동 모델을 비교한다. MASTER 전체 재현은 아니다.
- 두 모델 모두 폭 32·2 heads·60일 수익률 입력·504개 학습 가격·63일
  목표·동일 train-only scaler/purged split을 사용한다. Batch는 날짜 8개다.
  5 epoch 고정, seed 42/43/44로 반복하며 학습 순서는 한 반복에서 뒤집는다.
- 학습 전체, 최초/이후 epoch, 최초 추론과 준비 완료 후 추론 30회의 중앙값을
  구분한다. 추론 출력은 numpy로 읽어 완료를 기다린 뒤 시간을 기록한다.
- 시점은 2025-10-01, outcome은 2025-12-31이다. 단일 시점의 오차도
  저장하지만 성능 일반화 근거로 해석하지 않는다.
- 미래 가격의 학습/정규화 유입 방지와 다른 종목 입력의 영향이 종목 간
  attention을 켰을 때만 나타나는지, 종목 순서 재배열의 출력 일관성을 검사해
  집중 테스트 2개 통과. 전체 테스트와 서비스 변경은 수행하지 않았다.
- 실행 계약·원시 반복·요약: `logs/stock-attention10-20261124-cYvmeU/`.

## 측정 결과

- 종료 코드 0. 두 모델×3개 seed의 총 6회 학습과 추론 측정을 완료했다.
  TensorFlow 2.20.0, macOS arm64, CPU 장치만 사용했고 intra/inter thread는
  각각 1로 제한돼 있었다. 전체 main 실행은 52.62초, TensorFlow import는 5.73초였다.
- 5 epoch 학습 중앙값은 시간 attention만 6.628초, 종목 간 층 추가 시
  7.881초로 약 18.9% 증가했다. 첫 epoch에 초기 graph 준비가 포함된다.
- 준비 이후 epoch 중앙값은 각각 0.817초, 0.829초였다. 준비 이후 10종목
  동시 추론 중앙값은 각각 0.914ms, 0.957ms였다. 이 수치는 10종목 모델의
  특정 구현·입력에서 측정한 값이며 500종목으로 외삽하지 않는다.
- 이는 시간 요약 뒤 한 층의 종목 attention을 추가한 소형 ablation이다.
  MASTER의 시장 gating·특징·시간/종목 attention 교대 구조 전체와 다르며
  단일 평가 시점의 출력은 알파나 예측 성능 일반화 근거가 아니다.
