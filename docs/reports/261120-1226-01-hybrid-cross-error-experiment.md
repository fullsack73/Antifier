# 교차오차 반영·무시 혼합 비중 비교 실험

- 사용자 요청에 따라 기존 11개 섹터 22종목과 같은 2023-12-27~2025-10-01
  8개 평가 시점의 63일 예측 176건을 비교한다. 입력 가격을 189거래일
  확장해 모든 평가일에 현재 및 과거 3회 모두 504개 가격으로 학습한다.
- 비교하는 두 비중은 동일한 완료 과거 3개 기간의 오차를 사용한다.
  교차오차 무시는 기존 inverse-MSE, 반영은
  `(mean(e_T^2)-mean(e_A*e_T))/mean((e_A-e_T)^2)`를 사용한다.
  원시 비중을 0~1로 제한한 뒤 두 방식 모두 50:50 쪽으로 50% 수축한다.
  따라서 두 방식의 최종 ARIMA 비중은 25~75%로 동일하게 제한된다.
- 서비스 비중 계산은 변경하지 않는다. 실험은 같은 구성요소 예측과 과거
  오차를 공유해 모델 재학습 차이를 배제한다. 과거 오차 원자료도 기록한다.
- 입력 hash, 모델 source hash, 시점·종목·손실 기준은 실행 전에
  `logs/hybrid-cross-error-20261120-IkUBqE/experiment.json`에 고정했다.
  집계는 전체·섹터별 RMSE/MAE/rank IC, 두 혼합의 paired MSE 차이와
  날짜별 승패를 포함한다. 날짜 bootstrap은 8개 시점의 설명용 구간이다.
- 집중 회귀 30개와 `git diff --check` 통과. 전체 테스트는 실행하지 않았다.
  실험 완료 전에는 정확도 개선을 주장하지 않는다. 이미 소비된 과거 자료의
  진단이며 독립 승격 근거가 아니다. 기존 미실행 원인 진단을 재실행하지 않는다.

## 완료 결과

- 종료 코드 0, 176건 모두 완료. 모든 건에서 같은 504개 창으로 만든 완료
  과거 오차 3개가 확보됐으며 이력이 부족한 동일가중 fallback은 없었다.
- 교차오차 무시 혼합의 RMSE/MAE/rank IC는 0.139386/0.111906/0.06310,
  반영 혼합은 0.140441/0.113030/0.04969였다. 설명용 비교에서 교차오차
  반영이 전체 오차나 순위 정확도를 개선하지 못했다.
- 교차오차 반영의 절대 오차가 작은 행은 73/176건, 날짜별 MSE가 작은
  시점은 2/8개, 섹터별 RMSE가 작은 섹터는 정보기술·소재 2/11개였다.
- paired MSE 차이(반영−무시)는 +0.00029535, 날짜 bootstrap 설명용 95%
  구간은 [-0.00023002, 0.00069873]으로 0을 포함한다. 8개 공통 시장
  시점과 소비된 자료의 결과이므로 일반적 성능 열위의 확정 판정으로 쓰지 않는다.
- 동일가중 RMSE는 0.139131, Transformer 단독은 0.137157이었다.
  교차오차 반영 후보를 서비스에 적용하지 않았다.
- 상세 결과: `logs/hybrid-cross-error-20261120-IkUBqE/analysis.json`.
