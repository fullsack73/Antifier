# 혼합 가중치 평가의 학습 창 일치

- 과거 모델을 현재 학습 배열의 앞부분으로 재학습하던 방식을 제거했다.
  `train_all(prices, calibration_prices=None)`는 현재 학습 가격과 별도의
  과거 이력을 받는다. 과거 이력의 마지막 현재 창이 정확히 일치하고 값이
  유한·양수일 때만 사용한다.
- 현재 504개 가격·63일 예측이면 최소 693개의 과거 이력이 필요하다.
  과거 학습 창은 각각 이력의 0:504, 63:567, 126:630이고, 현재 창은
  189:693이다. 세 outcome은 현재 시점까지 완료되며 모든 학습 길이가 같다.
- 추가 이력이 없거나 불충분하면 과거 모델을 짧게 학습하지 않고 50:50을
  사용한다. 학습 이력만 넘기는 기존 서비스 호출에도 이 정책이 적용된다.
  현재 학습 창 길이를 504로 강제하지 않고 전달된 현재 창 길이를 유지한다.
- 비교 CLI는 각 평가일 이전의 추가 이력을 전달한다. 초기 평가일의 이력이
  부족하면 동일가중으로 처리하고 적용 여부를 결과에 기록한다. Transformer의
  epoch와 seed도 현재/과거에 동일하게 전달한다.
- 모델 및 forecast-rank 캐시 버전을 변경해 기존 잘못된 창의 예측을 재사용하지
  않는다. 가중치 공식 자체는 변경하지 않았다.
- 모델/후보/캐시/비교 관련 집중 검사 46개 통과. 이후 추가한 CLI의 현재 504개
  창·과거 이력 504/567/630/693개·미래 가격 제외 회귀를 포함해 비교 검사 2개
  통과. `git diff --check` 통과. 전체 테스트와 성능 재학습은 실행하지 않았다.
- 기존 forecast-failure 미실행 통제는 재실행하거나 완료 처리하지 않았다.
