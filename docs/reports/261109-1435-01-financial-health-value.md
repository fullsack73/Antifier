# Financial Score: 재무 건전성과 저평가 정도

- 일시: 2026-11-09 (Asia/Seoul)
- 목적: 수익률 예측·매매 신호 대신 재무 건전성과 상대 가격 수준을 설명합니다.
- 건전성 60%, 저평가 40%를 각각 표시하고 고정 비중으로 합산합니다. 성장률·베타·Forward P/E·PEG는 참고용입니다.
- 영역별 70% 데이터와 필수 지표를 요구하며, 부족하면 종합 점수는 null입니다. confidence 호환 필드는 데이터 충족률로 표시합니다.
- 건전성 절대 기준 보존, 심각한 지급능력/유동성 위험 시 상한, 부채비율 단위·0 값 오류, 0% 이익률 결측 오인, peer 캐시 조회 순서 의존성을 수정했습니다.
- 대표 peer는 지표별 최소 3개를 요구합니다. 원자료는 ticker별 공유 캐시로 재사용하며 평균 캐시는 제외 대상별로 분리합니다. 스크리너 캐시 namespace도 갱신했습니다.
- 금융회사·리츠 특화 모델, 현금흐름, 다년간 안정성, 내재가치 추정은 이번 범위에 추가하지 않았습니다. 가격 비교는 기존 Finviz/대표 peer 평균 또는 절대 기준을 사용합니다.
