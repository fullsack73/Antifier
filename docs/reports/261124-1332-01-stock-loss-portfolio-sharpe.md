# 횡단면 학습 목표와 포트폴리오 순 Sharpe 비교

- 사용자 요청: 상관·순위 학습 목표가 더 좋은 포트폴리오를 만드는지 비용 차감 Sharpe로 비교한다.
- 시간 attention 공동 모델·날짜별 횡단면 표준화 63일 로그수익률을 고정한다.
  MSE / 0.5 MSE + 0.5 (1-Pearson 상관) / 0.5 MSE + 0.5 pairwise softplus를 비교한다.
  순위 항은 같은 날짜의 i<j 쌍이며 실제 수익률 동률은 제외한다.
- 기존 11개 섹터 22종목, 가격 1008일, 504일 rolling 학습 창, 8개 평가 시점,
  seed 42/43/44, 5 epoch, batch 날짜 8개, 학습률 0.001을 공유한다. 총 72 fit.
  Train-only scaler와 63일 purge를 사용하며 다음 63일을 학습에 쓰지 않는다.
  에폭 수를 고정하며 내부 validation으로 후보나 epoch를 고르지 않는다.
- 점수 상위 5종목 각 20%를 목표로 하는 long-only 포트폴리오를 기존 거래 엔진으로
  재생한다. 동률은 ticker 사전순, GMV/전체 22종목 동일 비중을 대조군으로 둔다.
  신호는 직전 종가까지, 체결은 다음 거래일 종가다. 마지막 보유 구간은 62일이다.
  63거래일 리밸런싱, 비용 10 bps, 2% band, 35% 총 회전율 상한을 공유한다.
  첫 매수는 기존 엔진대로 회전율 상한을 면제하되 비용은 포함한다.
  band/회전율 제한에 따라 실제 보유는 목표 상위 5종목과 달라질 수 있다.
- 주 지표는 seed별 순 일수익률 Sharpe의 평균이다. 무위험 연 2%를 일별 복리 환산,
  252거래일 연율화한다. 초기 비용을 포함한 일수익률 복리가 summary 순자산과
  같은지 검증한다. 후보 대 MSE의 같은 seed별 63일 블록 bootstrap 2000회는 설명용이다.
- 이미 소비된 과거 자료이며 고정 생존 종목군이다. 3개 seed는 같은 미래 outcome의
  반복이며 독립 표본이 아니다. 최고 seed를 고르지 않고 서비스 모델도 변경하지 않는다.
- 신규 손실 gradient/방향, 상위 종목 선택, 기존 거래 엔진 통합 검사와 기존 입력 미래
  제외/attention 검사만 실행했다. 전체 테스트는 사용자 지시에 따라 실행하지 않았다.
