# Optimizer 설정 탭 정리

후보 탐색 설정이 2열 기본 폼의 중간 grid item으로 배치돼 접힌 상태에서도
옆 날짜 입력만큼 늘어나고 이후 섹션의 좌우 배치가 밀리는 문제를 수정했다.

- 후보 탐색을 기본 폼에서 제거하고 고급 설정의 전용 탭으로 이동.
- 최적화 조건 / 예측 설정 / 후보 탐색으로 구분. 값은 상위 상태에 유지.
- 후보 탭에서는 중복 접기를 제거하고 기존 preview/reset 기능 유지.
- 탭 선택 상태, 연결된 패널, 방향키/Home/End 이동과 포커스를 제공.
- 한국어/영어 제목을 추가. API 및 최적화 정책은 변경하지 않음.

검증: lint, 프론트엔드49개 테스트, build 통과. 390/848/1440px 브라우저에서
후보 탭 표시, 중첩 접기 없음, 가로 넘침 없음을 확인. 기존 bundle 크기 경고 유지.

## 사용자 피드백 반영

- 개발 중 locale 변경이 mounted i18n 리소스에 반영되지 않는 경로에 HMR 갱신을 추가하고
  탭 라벨에 읽을 수 있는 기본값을 제공했다. 실제 번역 리소스 로딩 회귀를 추가했다.
- 탭과 중복되는 Constraints/Forecast Controls 제목을 제거했다.
- 공유 후보 설정의 긴 설명을 접힌 안내로 이동하고 라벨을 단축했다.
  enable switch와 2열 숫자 입력을 Optimizer/백테스트에 동일 적용했다.
- lint, 프론트엔드51개 테스트, build 통과. 390/848px에서 넘침 없음과 접힌 안내 확인.
