# Taste skill을 활용한 백테스트 UI 개선

- 요청: 2026-11-14 사용자 요청. 백테스트 화면을 taste skill로 더 보기 좋게 개선한다.
- 사용할 skill: `design-taste-frontend` (`/Users/anarchytoast/.codex/skills/design-taste-frontend/SKILL.md`). 작업 시 최신 지침을 읽고 금융 분석 화면에 맞는 원칙을 적용한다.

## 작업 범위

- 기존 백테스트 화면과 Optimizer의 스타일을 먼저 점검하고, Antifier의 색상·타이포그래피·입력 컴포넌트와 일관되게 개선한다.
- CSV 업로드, 기간·거래 조건, 비교 전략, 후보 탐색 설정, 작업량 확인, 실행 진행률, 결과 표·차트의 정보 계층과 배치를 정리한다.
- 글자 크기·줄 길이·간격·정렬·설정 그룹·버튼 강조를 조정해 긴 설명과 숫자 입력이 뒤섞인 화면을 읽기 쉽게 만든다.
- 전체/부분 갱신, 고정 지도, 신규 예측/캐시, 예산 상한/실제 계산량을 시각적으로 구분한다. 고정 모드에서 사용하지 않는 갱신 간격은 비활성 상태임이 명확하게 보이게 한다.
- 데스크톱과 작은 화면 모두에서 입력·표·차트가 잘리거나 가로로 넘치지 않게 하고, 대비·키보드 조작·폼 라벨을 확인한다.
- 한국어·영어 문구를 함께 유지하며 기존 React 컴포넌트·CSS/i18n 패턴을 사용한다.

## 보존할 동작과 검증

- CSV 인식, 설정 전달, 예측·최적화 정책, 작업량 의미, 진행률·취소·재개·재연결, 결과 저장/조회 기능을 유지한다.
- [부분 갱신 진행 분모 보정](candidate-search-progress-denominator.md)과 연계하되 보기 좋게 만드는 과정에서 부정확한 숫자를 숨기거나 확정값처럼 표현하지 않는다.
- 변경 화면을 실제 렌더링해 데스크톱/작은 화면 및 실행 전·진행 중·실패·완료 상태를 점검한다.
- 프론트엔드 lint·테스트·빌드와 변경 흐름의 회귀 검증을 수행한다.
